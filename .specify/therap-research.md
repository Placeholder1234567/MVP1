## 3. AI Features — What Therap Actually Has

**Therap IS actively using AI.** They have a dedicated `/ai-tools-designed-for-human-services-providers/` page, multiple press releases, and conference presentations in 2026 focused on "Real AI, Real Solutions."

### AI Analyses (NEW 2026)
- Evaluates existing documentation to summarize data, identify trends, generate actionable insights
- Users select specific "AI Skills" tailored for health, person-centered, and daily documentation
- Features: Actionable Summaries, Trend Identification, Streamlined Service Planning
- Has dedicated video demo on the website

### Fatal Five Detection (NEW 2026)
- AI scans daily documentation for six life-threatening health conditions:
  - Aspiration, bowel obstruction, dehydration, GERD, sepsis, seizures
- Aggregates high-risk indicators into a single real-time dashboard
- Acts as a continuous safety net — catches things human reviewers might miss
- Has dedicated video demo

### QA Assistant
- AI reviews submitted documentation moments after submission
- Spots entries requiring closer review (e.g., daily note mentioning injury → should be an incident report)
- Issues timely, actionable alerts to staff
- Gives supervisors a comprehensive dashboard for flagged entries
- Specific alert type: "GER: Potential, Minimal Context" (press release from 2025-2026)

### AI Translation (NEW 2026)
- Powered by **Google Gemini**
- Converts PDF documentation into 100+ languages
- Specifically trained for IDD and HCBS terminology
- Interprets industry-specific language and abbreviations
- HIPAA-secure, built directly into Therap
- **Note:** This is the ONLY feature that uses a third-party AI model (Gemini). Other AI features use their own models.

### Automated Attendance
- Listed in navigation but less detailed publicly
- Appears to involve automated attendance verification

### AI Security Claims
- HIPAA-compliant
- "Never share sensitive information with third-party AI models" (except Gemini for translation)
- Models trained using "appropriately approved data"
- Same enterprise security, privacy, and encryption controls as core platform

### What Users Say About AI (from Capterra reviews, all 2026)

### What's Missing from Therap's AI
- **No voice-to-note** — Guad has this (MediaRecorder + Whisper + Claude)
- **No real-time AI drafting** — Therap AI summarizes AFTER documentation; Guad's Lomi drafts DURING
- **No conversational AI assistant** — Therap's AI is tool-based, not chat-based
- **No AI-powered shift coverage** — Guad's coverage engine is unique

## 4. Charting & Documentation Deep Dive (T-Log)

### T-Log = Therap's "Shift Notes"

T-Log is the primary daily documentation module. It's equivalent to Guad's shift notes feature.

### Exact T-Log Form Fields

**Required fields (2):**
1. **Type** — Checkboxes: Health, Notes, Follow-up, Behavior, Contacts, General (can select multiple)
2. **Summary** — Brief headline (e.g., "PM Shift 4-12 Midnight")

**Optional fields:**
3. Individual — Auto-populated
4. Program — Auto-populated
5. Entered By — Auto-populated
6. Notification Level — Low / Medium / High dropdown
7. Description — Large free-text field (~10,000 char limit) — this is where the actual narrative goes
8. Time In — Time picker
9. Time Out — Time picker
10. Reporter — Search field
11. Reported On — Date/time picker
12. Document Attachment — File upload / scan
13. Photo — Image upload
14. Video — Secure video documentation

### T-Log Workflow (5 Steps)
1. Navigate to Individual Tab → T-Log → "New"
2. Select Location/Program from table
3. Select Individual from list (Last Name, First Name, ID, DOB)
4. Verify correct person/program → Fill in Type, Summary, Description, optional fields
5. Click Submit → System confirms with unique form ID (e.g., "TTL-ICARESC-M4B4UHBZ34RQZ")

### Post-Submission Behavior
- Entry added to To-Do dashboard for all caseload staff
- Priority based on Notification Level
- Other staff can add follow-up comments
- Searchable by date range, individual, status
- Reports generated from T-Log data

### T-Log Timing
- A typical T-Log entry takes **3-10 minutes** depending on detail
- DSPs report spending **30-60+ minutes per shift** on ALL Therap documentation (not just T-Logs)
- Dungarvin case study: new module took "20 minutes" vs "two hours" on paper
- Happy Haven: "documentation was cut down tremendously"

### ISP Goal Tracking (Separate from T-Log)
- ISP Programs define teaching programs with goals/objectives
- Scoring methods: Prompt Levels, Percentages, Time Durations, Task Counts
- Task Analysis: breaking complex goals into manageable steps
- Staff select score from dropdown for each task (under 1 minute per goal)
- Automated progress reports with graphs and charts
- Links directly to T-Log for narrative + quantitative combined view

### Charting the LifeCourse
- Therap integrates "Charting the LifeCourse" person-centered planning tools
- Life Trajectory, Vision Tool, Integrated Supports Star
- These are person-centered planning frameworks, not data charting

### Navigation Structure
Therap organizes under tabs:
- **To Do** — Dashboard with prioritized action items
- **Individual** — T-Log, GER, ISP Data, Staff Action Plan
- **Health** — EHR, MAR, Health Tracking
- **Agency** — Agency-level reports
- **Billing** — Claims
- **Admin** — Settings
- **Agency Reports** — Dashboards

## 5. Behavioral Data (BData) & Health Tracking

### BData Module — For BCBAs and Behavior Programs

**Data Collection Methods:**
| Method | Description |
|--------|-------------|
| Frequency/Event Recording | Counting discrete occurrences (rate or raw count) |
| Duration Recording | Start/stop timing of behavior episodes |
| Partial Interval | Was behavior observed at any point during interval? |
| Whole Interval | Did behavior persist for entire interval? |
| Momentary Time Sampling | Was behavior occurring at exact moment interval ended? |
| ABC Data | Antecedent-Behavior-Consequence logging |
| Task Analysis | Step-by-step mastery tracking (independent, verbal prompt, physical prompt) |
| Trial-by-Trial | Correct/incorrect responses in discrete trial training |
| Likert/Rating Scale | Configurable subjective measures |

**How BData Works:**
1. BCBA creates Behavior Program (operational definition, measurement method, mastery criteria)
2. Therap generates digital data sheets
3. DSPs/RBTs record observations on tablet/phone (counters, timers, interval grids)
4. Submissions reviewed and approved by supervisors
5. System auto-aggregates into summary statistics and graphs

**Graphs & Visualizations:**
- Line graphs (primary — data points over sessions/dates)
- Bar charts (frequency comparisons across categories)
- Cumulative graphs (skill acquisition acceleration/deceleration)
- Phase change lines (baseline to intervention markers)
- Trend lines / aim lines (expected trajectory)
- Goal/criterion lines (horizontal reference)
- Multi-behavior overlay (compare behaviors on one graph)
- Export to PDF for behavior plans and ISP meetings

**Visual Quality Assessment:** Graphs are **functional and clinical** — ABA convention single-subject design. **Not** interactive, zoomable, or modern. Colors are basic. Render as static images. Utilitarian, not polished.

**BCBA Feedback:**
- **Strengths:** Integration with broader EHR, accessible to DSPs, meets Medicaid audit requirements
- **Weaknesses:** Graphing less flexible than CentralReach/Catalyst; not clinic-optimized; data export cumbersome; no advanced ABC pattern analysis

### Health Tracking Module

**Vital Signs:**
- Blood pressure (with position: sitting, standing, supine)
- Heart rate/pulse (BPM, regularity)
- Temperature (oral, tympanic, axillary, rectal; F/C)
- Respiratory rate
- Weight (with BMI auto-calc)
- Blood glucose (fasting vs non-fasting)
- Oxygen saturation (SpO2)
- Pain scale (numeric or FACES for non-verbal)

**Seizure Tracking (highly valued for IDD):**
- Seizure type classification (tonic-clonic, absence, myoclonic, atonic, focal, status epilepticus)
- Date, time, duration
- Pre-ictal observations (triggers: missed meds, illness, sleep deprivation)
- Ictal description (body parts, eye deviation, incontinence, cyanosis)
- Post-ictal state (confusion, sleepiness, duration)
- Interventions (positioning, rescue meds, 911)
- Automatic seizure log summaries with counts by type
- Threshold alerts (e.g., ">3 seizures in 24 hours" → notify nurse)

**Additional Tracking:**
- Bowel movements (Bristol Stool Scale, alerts for extended periods)
- Menstrual cycle (onset, flow, duration, symptoms)
- Sleep (sleep/wake times, quality, nighttime checks)
- Skin/wound (body map location, size, staging, photo attachment)

### eMAR (Medication Administration)
- Scheduled medication passes with time-based grids
- Administration recording: Administered, Refused, Held, Not Available, Absent
- PRN medications with indication, effectiveness follow-up
- Controlled substance tracking (two-staff witness, count verification)
- Medication error reporting (wrong med/dose/time/route/person, omission)
- Drug interaction checks (basic)
- MAR printouts for physician review and audits
- Complete immutable audit trail

## 6. Incident Reporting (GER) & Compliance

### GER Workflow (5-Step Lifecycle)

1. **Initial Report** — Staff log incidents via web/mobile. Structured event types. Video upload supported.
2. **Automated Alerts** — SComm alerts, email/SMS, push notifications. Tiered priority (high/medium/low). 4-hour ANE call-in deadline achievable digitally.
3. **Review & Investigation** — GER Resolution module. Witness statements. Evidence attachment. Corrective actions. Investigator tasks tracked.
4. **ANE Special Handling** — Abuse/neglect/exploitation reports auto-restrict visibility. Only specific admin permissions can access.
5. **Resolution & Pattern Analysis** — BI dashboards for trends across programs, locations, individuals, incident types. Root cause analysis.

**The mobile app is Therap's single biggest weakness.**

### What Works on Mobile
- T-Log entry (daily notes)
- GER (incident reports)
- ISP Data collection
- Attendance check-in/check-out
- Health tracking (vitals, meds, seizures)
- SComm messaging
- Photo/image upload
- Signature capture
- EVV (separate app) with GPS

### What's Missing/Limited on Mobile
- Full ISP authoring (web only)
- Admin configuration
- Advanced reporting & analytics
- Billing modules
- Form customization
- User/role management
- Full dashboard views
- Batch operations

### Critical Mobile Problems
1. **"Mobile web wrapper"** — Not a true native app; mirrors desktop web version
2. **Crashes frequently** — Especially during form submission
3. **Session timeouts** — Forces re-login, causes data loss
4. **No auto-save/drafts** — Lost work on crash or timeout
5. **Very limited offline** — Most features need active internet
6. **Small text, unoptimized forms** — Not designed for phone screens
7. **No biometric login** — No Face ID / fingerprint (historically)
8. **No dark mode**
9. **High battery drain** — Especially with EVV GPS tracking
10. **GPS inaccuracy** — Shows worker not at location when they were; impacts pay

### DSP Reality
- Many DSPs use personal phones (no employer-provided devices)
- Battery drain, data charges, storage concerns
- Workaround culture: write on paper → enter in Therap later
- Mobile documentation is SLOWER than desktop

## 9. Integrations & API (or Lack Thereof)

### The Hard Truth: Therap Has No Public API

| Integration Aspect | Reality |
|-------------------|---------|
| Public REST API | **NO** |
| Developer Portal | **NO** |
| Swagger/OpenAPI Spec | **NO** |
| API Key Self-Service | **NO** |
| Webhooks | **NO** |
| FHIR R4 API | **Not publicly available** |
| Standard SAML/OIDC SSO | **Not for general customers** |
| App Store/Marketplace | **NO** |

### How Data Actually Gets In/Out
1. **Manual report exports** (most common) — CSV, PDF, Excel
2. **Scheduled email reports** — For regular operational data
3. **Billing file downloads** — 837P/837I claim files
4. **Therap Connect** — Branded integration layer (requires formal contract)
5. **State-mandated data feeds** — Where states require it
6. **Screen scraping / copy-paste** — Not endorsed but practiced
7. **Therap data services** — For migrations (work directly with Therap team)

### What Therap DOES Integrate With
- State Medicaid systems (MMIS) — Direct claim submission
- EVV aggregators (Sandata, HHAeXchange)
- Clearinghouses (Availity, Office Ally, Trizetto, Change Healthcare)
- Relias (training/LMS export)
- CellTrak (some state deployments)
- Smart devices via Therap Connect (Withings, Fitbit, iHealth)
- Arlyn Wheelchair Scales
- Some pharmacy systems (data import, not live HL7)

### Competitive Weakness
This closed ecosystem is Therap's **most significant competitive weakness** for agencies needing interoperability. Competitors like CaseWorthy, iCareManager, and Netsmart/myEvolv all offer API access.

**For Guad/Nticare:** This means Therap users who want to add Guad's capabilities CANNOT easily connect the two systems. However, it also means agencies frustrated by Therap's closed nature are looking for alternatives that integrate better — an opportunity for Guad.

## 10. Pricing & Business Model

### Pricing Structure
| Aspect | Detail |
|--------|--------|
| Model | Per individual served per month (NOT per seat/user) |
| Starting Price | $130/month (for small agencies) |
| Staff Accounts | Unlimited (no per-user licensing) |
| Pricing Public? | No — quote-based, contact sales |
| Setup/Implementation Fee | None |
| Support | Included |

### Estimated Cost Ranges
- **Direct provider:** ~$5-$15+ per individual per month
- **State contract bulk:** ~$3-$8 per individual per month
- **Statewide contracts:** $500K-$5M+ annually
- **Implementation costs:** $2,000-$20,000+ (training scope dependent)

### What Drives Cost Up
- Number of individuals served (volume tiers)
- Number of modules selected (core + add-ons)
- Direct purchase vs state agreement
- Contract length
- Implementation & training scope

### State Mandate Economics
When a state mandates Therap:
- All waiver providers MUST use it
- State typically pays or subsidizes the subscription
- Providers have no choice of alternative
- Creates a captive market with reduced competitive pressure
- Contracts are 3-5 years with renewal options

### Revenue Model
- **Primary:** State government contracts (majority of revenue)
- **Secondary:** Direct provider sales in non-mandate states
- **Tertiary:** Multi-state enterprise agreements

## 11. Customer Complaints — Direct Quotes & Pain Points

### TOP 15 PAIN POINTS (Ranked by Frequency)

**1. Session Timeouts = Lost Work** (THE #1 RAGE COMPLAINT)
> DSPs report spending 15-20 minutes writing a detailed note, only to have the session expire and lose ALL their work when clicking "Save." This is described as "rage-inducing."

Staff coping mechanism: Type notes in a separate app first, then copy-paste into Therap.

**2. Outdated, Clunky UI**
> "Looks like a government website from 2005." "Clunky," "ugly," "non-intuitive."

**3. Excessive Documentation Time**
> "I spend more time on Therap than with my clients." DSPs report 1-2 hours per shift on documentation.

**4. Poor Mobile Experience**
> "The mobile interface is nearly unusable — forms don't render well, the app crashes, sessions time out."

**5. System Slowness & Outages**
> Page loads take 10-30 seconds during peak times. State-mandated incident reporting deadlines missed due to outages.

**6. Complex Administration**
> "Setting up programs requires a PhD in Therap." No bulk user management despite 40-60% annual DSP turnover.

**7. Captive Market Resentment**
> "In several states, we have NO CHOICE. Therap has less incentive to improve because providers cannot switch."

**8. Expensive Pricing**
> "We pay a premium for a system that looks like it was built 20 years ago." Per-individual costs add up; module add-ons drive costs higher.

**9. Inadequate Customer Support**
> Phone waits can be 30+ minutes. Email tickets take days. Training materials are "outdated, insufficient, and hard to find."

**10. Poor Data Export & Integration**
> CSV exports are "poorly formatted." No API. Historical data extraction is "extremely difficult" — creates vendor lock-in.

**11. Limited Reporting**
> "Extracting meaningful data requires exporting to Excel and manipulating it." Custom report building is very limited.

**12. Rigid Templates**
> "Many agencies change their workflows to match Therap, not the other way around."

**13. Training Burden**
> With 40-60% annual DSP turnover, agencies constantly retrain. Therap charges for training sessions.

**14. Redundant Data Entry**
> Same information must be entered in multiple modules (T-Logs, data collection, ISP tracking).

**15. Medication Module Issues**
> Confusing PRN documentation, medication change interfaces, printing problems.

### Platform-Specific Feedback

**From Reddit (r/DSP, r/socialwork, r/disability):**
- "I spend more time on Therap than with my clients"
- Session timeout complaints are near-universal
- Workaround culture: paper notes → enter later

## 15. Guad's Strategic Advantages Over Therap

### 1. AI-First Architecture
Therap bolted AI onto a 20-year-old platform. Guad was built with AI (Lomi) from day one.
- **Lomi drafts notes in real-time** during documentation, not after
- **Voice-to-note** (Whisper + Claude) — Therap has nothing comparable
- **Conversational AI** — Lomi is a chat assistant; Therap's AI is dashboard-only
- **Behavior note generation** — Structured output from simple prompts
- **Day summaries** — AI-generated shift summaries

### 2. Modern Mobile-First UX
Therap's app gets 2-star ratings. Guad is built mobile-first.
- Clean, modern design (Figtree + Georgia fonts, blue/lemon/warm palette)
- 420px mobile-first layout with desktop sidebar at 900px
- Bottom sheets for quick actions
- Setup wizard for new users
- **No session timeouts destroying work** (PowerSync OPFS persistence in production; prototype uses localStorage)

### 3. GPS Clock-In with Haversine
Therap has EVV but it's a separate app with GPS accuracy complaints. Guad has integrated GPS clock-in with configurable radius per home.

### 4. Automated Shift Coverage
Guad's coverage engine (eligibility rules, home assignment, hours cap, med certification) has no equivalent in Therap or any competitor.

### 5. Zero-Friction Onboarding
- No complex admin setup
- Dev sign-in for testing
- Setup wizard
- No per-individual pricing barrier

### 6. Offline-Resilient
PowerSync OPFS persistence means work is never lost. (Rebuild target -- the current prototype uses localStorage for in-progress form data but requires network for initial load; production will add service worker + PWA manifest for true offline capability. See offline-sync.md.) Therap users live in fear of session timeouts.

### 7. Integration-Ready Architecture
SvelteKit 2 + Svelte 5 runes + Supabase + tRPC = easy to extend. (Note: Guad references in sections 15-16 describe the production architecture. The vanilla JS prototype is documented in CLAUDE.md.) Therap's closed ecosystem is its biggest weakness.
