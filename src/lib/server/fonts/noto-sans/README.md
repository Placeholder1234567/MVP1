# Noto Sans PDF fallback

Unmodified static hinted Noto Sans Regular and SemiBold, version 2.008, from [notofonts/noto-fonts](https://github.com/notofonts/noto-fonts/tree/ffebf8c1ee449e544955a7e813c54f9b73848eac/hinted/ttf/NotoSans), downloaded 2026-10-23 UTC. Copyright and SIL Open Font License 1.1 are preserved in OFL.txt. The font software is embedded/subset by PDFKit, never shipped as an application UI font.

SHA-256:

- NotoSans-Regular.ttf: b85c38ecea8a7cfb39c24e395a4007474fa5a4fc864f6ee33309eb4948d232d5
- NotoSans-SemiBold.ttf: 87a8b90ece1e89746b544e4e086f85a3710e41485a8078f9be874837dfad45d5
- OFL.txt: 0dab92d0544f7b233403f14b84a663bdbfa746982eda629e7f4f9ffe1b036feb

Figtree stays the first choice. A report uses Noto Sans only when both Noto faces cover every non-whitespace character and Figtree cannot. This adds Greek, Cyrillic and extended Latin coverage; it is not universal Unicode or right-to-left script support. Unknown glyphs still cause refusal and the CSV/HTML fallback. No transliteration or missing-history reconstruction.
