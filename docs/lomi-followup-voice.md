# Speak additional observations in Lomi review

The documented Mode 3 charting flow includes spoken follow-ups, but the shift-note review previously offered only a typed follow-up field. Staff can now choose **Speak follow-up · up to 30 seconds** beside that existing field when transcription capability is available. The same capture/transcription controller used for section observations supplies text; no new provider or model endpoint is added.

Speech populates observations only. Staff separately request section suggestions, compare the proposal, apply or discard it, use the reviewed draft in the note, and save/sign. Routing and clearing actions are disabled while voice is active. Typed follow-ups remain available without transcription configuration. Short section/follow-up voice needs a connection: the mic is disabled offline, typed input stays enabled, and a connection loss stops capture with an explicit message. The existing full-note encrypted offline recording queue is unchanged. No automatic clinical fact, goal score, model routing, note save or signature is introduced.

The 2,000-character follow-up limit uses the existing whole-text append rule. A transcript that does not fit remains visibly available for explicit addition or discard; it is not silently shortened. Its unadded live copy is volatile, with the existing on-screen warning and dirty-work navigation behavior.

The existing synthetic microphone overflow regression now also exercises follow-ups on desktop and phone. It preserves the full negation/time/quantity/Unicode transcript, verifies disabled short-clip recording with enabled typing offline, zero transcription on reconnect alone, zero routing requests until the explicit Suggest action, checks the resulting real local-fallback proposal, and leaves the underlying care note/signature unchanged. It retains the prior full-note, section and offline-recording cases, axe and overflow checks. The follow-up browser fixture uses a supervisor's unsigned shift-note review; caregiver routing authorization is covered by the existing care-record integration tests. Real Chirp accuracy, latency and staff usability remain unverified acceptance gates.
